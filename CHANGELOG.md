# PICoin Project Changelog

## Release 1.0
**Release Date:** July 2026

---

## Overview

This release establishes the initial public documentation and architectural foundation of the PICoin Project.

The documentation has undergone a comprehensive audit to ensure consistency, transparency, and alignment across the official website and GitHub repository.

---

## Highlights

### Documentation

- Completed the first full documentation audit.
- Unified terminology across all project documentation.
- Introduced the **PICoin Project Style Guide**.
- Standardized the use of **PICoin Project** and **PICoin** throughout the documentation.

### Website

- Updated HTML documentation.
- Added consistent metadata (Title, Description, Open Graph, Canonical URLs).
- Synchronized website documentation with the GitHub repository.

### Core Documents

- White Paper updated and synchronized.
- Regulation reviewed and aligned with the current project architecture.
- Manifesto revised to reflect the Project philosophy.
- Roadmap updated to reflect the current development strategy.
- Stellar Wallet Structure documentation updated.

### Technical Infrastructure

- Updated `stellar.toml`.
- Verified Stellar wallet allocation documentation.
- Improved consistency of public technical information.

### Architecture

- Removed obsolete NFT-related concepts.
- Simplified the long-term Project model.
- Improved documentation consistency and transparency.

---

## Result

The PICoin Project now provides:

- a unified documentation standard;
- consistent terminology;
- synchronized website and GitHub documentation;
- documented technical architecture;
- a stable foundation for future development.
